## 2. 概率模型

### 2.1 均匀分布假设

如果每行独立随机选择排列，且分布均匀：

```
P(单列满足 AllDifferent) = 16! / 16^16
                          ≈ 2.1×10^13 / 1.8×10^19
                          ≈ 1.13×10^-6

P(16 列全部满足) = (1.13×10^-6)^16
                 ≈ 7.5×10^-96
```

### 2.2 非均匀分布修正

**实际分布极度不均匀**：

```
最大频率比率: 2,485.8x (列 5)
稀缺值次数: 164 次（某些值在某些列仅出现 164 次）
```

非均匀分布使有效概率进一步降低：

```
P(实际) ≈ P(均匀) × (不均匀因子)
       ≈ 7.5×10^-96 × 0.01
       ≈ 7.5×10^-98
```

### 2.3 指数衰减模型

设每行选择受前 k 行约束影响，有效概率为 p_k：

| 行 | 约束层数 | 有效概率 p_k（估计） |
|---|---------|---------------------|
| 1 | 0 | 1.000 (100% 自由) |
| 2 | 1 | p_1 ≈ ? |
| 3 | 2 | p_2 ≈ ? |
| ... | ... | ... |
| 16 | 15 | p_15 ≈ ? |

**总有效解数估计**：

```
E[S] ≈ N_1 × p_1 × p_2 × ... × p_15
```

| 假设 p_k | E[S] 估计 | 结论 |
|---------|-----------|------|
| p_k ≈ 0.5 | N × 3.05×10^-5 ≈ 34 | 可能有几十个解 |
| p_k ≈ 0.1 | N × 10^-15 ≈ 10^-9 | **解空间几乎为空** |
| p_k ≈ 0.01 | N × 10^-30 ≈ 10^-24 | 解空间为空 |

## 4. 存在性判断

### 4.1 理论存在性条件

```
解空间非空的条件：
E[S] ≥ 1  （期望解数 ≥ 1）

即：N × p^16 ≥ 1

求解：p ≥ N^(-1/16)
      p ≥ (1.1×10^6)^(-1/16)
      p ≥ 0.52
```

**推论**：
- 如果平均每步有效概率 p ≥ 0.52，解空间非空
- 如果 p < 0.52，期望解数 < 1，解空间可能为空

### 4.2 从数据推断

```
从瓶颈分析：
- 行 9 仅有 164 个排列（约束最紧）
- 最严重瓶颈单元格仅有 10 个支持排列

从频率不均匀性：
- 最大频率比率 2,485.8x
- 稀缺值分布极不均匀

推断：实际有效概率 p 可能 < 0.1
```

### 4.3 结论

```
⚠️ 关键判断：

如果 p < 0.52，则 E[S] < 1

从数据看：
- 最大频率比率极高
- 瓶颈单元格支持数极少
- 分布极度不均匀

→ 实际 p 可能远小于 0.52
→ 期望解数 E[S] 可能 < 1
→ 解空间为空的概率较高

但如果存在解：
- 解的数量可能为 1（唯一解！）
- 或极少数几个解
```
