## 3. 搜索空間科學分析

### 3.1 理論計算

| 參數 | 值 |
|------|-----|
| 總格數 | 256 |
| 已知錨點 | 92 (35.9%) |
| 未知位點 | 164 (64.1%) |
| 符闔行固定 | C、D、I 行 (48 格完全固定) |
| 非符闔行未知 | 13 行 × 16 格 = 208 格 |

**理論搜索空間**：
- 非符闔行 13 行，每行 16 格，理論上 ~16^208
- 但存在列 AllDifferent 約束 → 減少至 ~10^40
- 實際本質解數 23 → **解密度 ~23 / 10^40 ≈ 2.3 × 10^-39**

### 3.2 為何搜索如此困難？

**V28 遺傳算法的啟示**：
- 遺傳算法理論覆蓋率 ~10^-35
- 實際找到 23 個解已屬極不易
- 說明搜索空間中**真正的解是「稀疏中的極稀疏」**

**V29 Latin Square 的啟示**：
- 列約束優先將搜索空間減少至 ~10^20
- 但回溯搜索在 200 個候選中僅找到 23 個解
- 證明**每 10^18 個 Latin Square 中僅有 1 個是有效解**

## 4. 基因指紋聚類分析（精確確認）

### 4.1 23 個本質解的聚類特徵

| 本質解 ID | Grid Hash | 序列出現次數 | 簇大小 |
|-----------|-----------|-------------|--------|
| 1 | 253c84ff... | 1 | 1 |

| 3 | 6c9e3925... | 1 | 1 |
| ... | ... | ... | ... |
| 23 | da7e0aa9... | 1 | 1 |

**關鍵發現**：
- **所有 23 個簇大小均為 1** → 無對稱/等價解
- **所有解均含 1 次「7 15 3 9」序列** → 序列約束有效
- **首宮特徵相似但不完全相同** → 除固定序列外其餘格有變化

### 4.2 距離計算（層次聚類閾值 = 0.15）

距離公式：
```
dist = 0.40 × (行不同比例) + 0.25 × (首宮不同) + 0.15 × (序列差異) + 0.20 × (首行不同)
```

- 任意兩個解的行差異 = 13 行/16 行 = 0.8125
- 距離 = 0.40 × 0.8125 + 0.15 × 0 + 0.20 × (首行差異) ≈ 0.325 + ...
- **所有成對距離 > 0.15** → 23 個獨立簇 ✓

**仲裁申請**：
1. C/D/I 符闔行的列/宮約束應從符闔排列中推導
2. 非符闔行保持標準數獨約束
3. 符闔行與非符闔行間允許列/宮跨值

**若仲裁通過**：
- 列/宮衝突將消失
