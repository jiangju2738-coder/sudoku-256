### 適應度函數

```
Fitness = 0.1 × RowFitness + 0.5 × ColFitness + 0.4 × BoxFitness + 0.1 × KnownMatch

其中:
- RowFitness: 每行16個值是否AllDifferent (0~1)
- ColFitness: 每列16個值是否AllDifferent (0~1)
- BoxFitness: 每宮16個值是否AllDifferent (0~1)
- KnownMatch: 已知位置匹配率 (0~1)
```
