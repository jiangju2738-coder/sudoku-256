# 符阖排列与数独约束对称性分析

## 用户洞见

> "超級大數獨標準初盤解本身就已經具備包含行 列 宮三者共衕的約束規則條件"

**核心观点**：标准数独的三约束（行/列/宫）是**等价/对偶**的，符阖排列打破了这种对称性。

---

## 1. 标准 16×16 数独的对称性

### 约束结构

```
约束类型          数量     结构
─────────────────────────────────────
行 AllDiff        16       R0...R15
列 AllDiff        16       C0...C15  
宫 AllDiff        16       B00...B33 (4×4 宫格)
─────────────────────────────────────
总计              48
```

### 对称群结构

标准 16×16 数独的**完整对称群**包括：

| 变换类型 | 操作 | 保持约束 |
|----------|------|----------|
| **值置换** | σ: {1..16} → {1..16} | ✅ 行/列/宫 |
| **行置换** | π_r: 行索引置换（保持块结构） | ✅ 行/列/宫 |
| **列置换** | π_c: 列索引置换（保持块结构） | ✅ 行/列/宫 |
| **转置** | T: (r,c) → (c,r) | ✅ 行↔列互换，宫保持 |
| **块置换** | P: 4×4 宫格置换 | ✅ 行/列/宫 |

**阶数估计**：
- 值置换：16! ≈ 2.09×10¹³
- 行/列块置换：(4!)² × (4!)² ≈ 8.3×10⁴
- 转置：2
- **总计**：≈ 3.5×10¹⁸ 种对称变换

### 约束的对偶性

```
行约束 R_i:  {x[i,j] | j=0..15}  所有不同
列约束 C_j:  {x[i,j] | i=0..15}  所有不同
宫约束 B_k:  {x[i,j] | (i,j)∈B_k} 所有不同

关键观察：
- R_i 和 C_j 通过转置 T 互换
- B_k 在行/列置换下保持结构
- 三约束在对称群下是"等价"的
```

## 2. 符阖排列如何打破对称性

### 符阖排列的本质

符阖排列约束形式：
```
Row i:  (x[i,0], x[i,1], ..., x[i,15]) ∈ Permutations_i
```

**关键问题**：
1. **行不等价**：Row 3 有 407,669 个排列，Row 9 只有 164 个
2. **列破坏**：排列约束不尊重列 AllDiff
3. **值不对称**：每行值域分布不同

### 对称性破坏矩阵

```
对称操作        标准数独    符阖排列数独
──────────────────────────────────────────
值置换 σ        ✅ 保持     ❌ 打破（排列不封闭）
行置换 π_r      ✅ 保持     ❌ 打破（排列集不同）
列置换 π_c      ✅ 保持     ❌ 打破
转置 T          ✅ 保持     ❌ 打破（行约束≠列约束）
宫置换 P        ✅ 保持     ⚠️ 部分打破
──────────────────────────────────────────
```

## 3. "同心圆"约束的数学解释

用户提到：**"256 个数字满足同心圆约束——X 行 Y 列 Z 宫的距离中点相一致"**

### 解释

这是指一种**超约束**：每个单元格 (i,j) 的值由其在行、列、宫的"位置权重"决定。

**假设的同心圆结构**：
```
                宫 B
             ┌───────┐
        列 C │   ●   │ 行 R
             │  (i,j)│
             └───────┘

"距离中点" = 单元格到中心的某种度量
```

### 数学表达

定义**三约束距离函数** d(r,c,b)：

```
d_row(i,j)    = |j - 7.5|     (列偏移，中点=7.5)
d_col(i,j)    = |i - 7.5|     (行偏移)
d_block(i,j)  = distance to block center

"同心圆约束": 对于所有 (i,j) ∈ 256 cells:
    f(x[i,j], d_row, d_col, d_block) = 常数

或者更抽象：
    ∃ 函数 F: Value × Position → {0,1}
    使得 F(x[i,j], (i,j)) 对全解一致
```

### 与符阖排列的关系

符阖排列本质上是：
```
Row i 的约束：{ (v0, v1, ..., v15) } ∈ P_i
```

这等价于说：
```
每个单元格 (i,j) 的值域取决于：
    V(i,j) = { v | ∃ p ∈ P_i 使得 p[j] = v }
```

**问题**：
- V(i,j) 不一定等于 V(i',j)（列不一致）
- V(i,j) 不一定等于 V(i,j')（行内不一致）
- 违反"同心圆"均匀性

## 4. 不可行性根源

### CP-SAT 发现的 INFEASIBLE

```
Phase 1 (标准): OPTIMAL, 0.24s
Phase 2 (+符阖): INFEASIBLE, 4.65s
```

### 约束冲突诊断

| 冲突类型 | 描述 |
|----------|------|
| **行-列冲突** | 排列约束强制某些值在同一列出现 |
| **行-宫冲突** | 排列约束与块 AllDiff 冲突 |
| **值分布冲突** | 某些值在某些位置"被禁止"但必须在 |

### 定量分析

```
约束强度排序（从紧到松）：
Row 9:  164 排列   ← 最紧
Row 6:  359 排列
Row 1:  8,731 排列
Row 3:  407,669 排列 ← 最松

矛盾产生：
- 行 9 的 164 个排列中，某些列位置值域 < 16
- 但列 AllDiff 要求每列 16 个不同值
- 当 16 行的值域并集 < 16 时，产生不可满足
```

## 5. 结论与启示

### 核心结论

1. **标准数独对称性**：行/列/宫三约束在对称群下等价
2. **符阖排列破坏对称**：引入行特异性，打破对偶性
3. **不可行性来源**：对称性破坏 → 约束冲突 → 搜索空间为空

### "同心圆"约束的条件

若要符阖排列不破坏对称性，需要：

```
∀ i, i', j, j': 
    |P_i| = |P_i'|  （每行排列数相同）
    AND
    V(i,j) = V(i',j) （每列值域相同）
    AND
    ∃ σ: Permutations_i → Permutations_{i'}
        使得 σ 是值置换
```

这等价于：符阖排列集必须是**行对称的**（所有行的排列集通过值置换等价）。
