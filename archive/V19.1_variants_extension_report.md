## 2. 核心技術實現

### 2.1 SudokuVariant 抽象基類

```python
class SudokuVariant(ABC):
    """數獨變體抽象基類"""
    
    @abstractmethod
    def validate_solution(self, grid, known_positions) -> Dict:
        """驗證解的有效性"""
        pass
    
    @abstractmethod
    def compute_constraint_fitness(self, grid, known_positions) -> float:
        """計算變體約束適應度"""
        pass
    
    @abstractmethod
    def get_additional_constraints(self) -> Dict:
        """獲取變體特有約束定義"""
        pass
```

### 2.2 X Sudoku 變體

**約束定義**：
- 主對角線 (0,0) → (15,15): 16 個位置必須 AllDifferent

### 2.3 Killer Sudoku 變體

**約束定義**：
- **Cage 求和**: 每個 Cage 內數字之和必須等於 target_sum
- **Cage 唯一性**: 每個 Cage 內數字不能重複

**基因指紋擴展**：
```python
# cage_sum_dimensions (20D) - 每個 Cage 的求和滿足度
# cage_unique_dimensions (16D) - 每個 Cage 的唯一性滿足度
```
