## 核心推论

### 1. 92锚点 + C191620 ≠ 符阖原题

```
CP-SAT在92锚点+C191620下找到唯一解，
但该解与txt终局解盘只有13.3%的行完全匹配。

证明：txt终局解盘不是通过92锚点+C191620推导出来的。
```

### 2. txt终局解盘的来源

```
txt终局解盘来自原始符阖排列组闔（1,360,849个排列）

它满足的约束：
(1) 92锚点约束 —— 部分满足（有4个冲突锚点）
(2) 数独三约束（行/列/宫） —— 满足
(3) 符阖排列组闔约束 —— 关键！每行来自原始1,360,849排列

backup_fuyi/ 只是第(3)个约束的筛选子集（约1.5%）
```

### 3. backup_fuyi/ 的真实含义

| 特征 | 数值 |
|------|------|
| 总排列数 | 20,603个 |
| 每行规模 | ~1,300个（高度一致） |
| 固定位置 | 55个（占256宫的21.5%） |
| 匹配92锚点 | 51个（92.7%） |
| 额外固定列 | 4个（来自列解集约束） |

```
backup_fuyi/ = 从原始1,360,849排列中筛选的子集

筛选逻辑：
1. 用92锚点中的51个位置作为固定列
2. 从列解集中选择4个额外固定值
3. 生成满足这些固定列约束的所有排列
```

## 最终结论

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  符阖原题完整解 = 满足以下三个约束的解：                            │

│  (1) 92锚点约束                                                     │
│  (2) 数独三约束（行/列/宫互斥）                                     │
```
