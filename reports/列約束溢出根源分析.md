## 三、極大列相容集理論

### 3.1 定理

> **定理**：任何 16×16 Sudoku 的 16 行構成「極大列相容集」。
> 
> 即：不存在第 17 行與這 16 行同時滿足列約束。

### 3.2 證明

**設**：S = {R₀, R₁, ..., R₁₅} 是一個 16×16 Sudoku 的 16 行

**要證**：不存在行 R₁₆ 使得 {R₀, ..., R₁₅, R₁₆} 滿足列約束

**證明**：
```
對任意列 j (0 ≤ j ≤ 15)：

列約束要求：{R₀[j], R₁[j], ..., R₁₅[j], R₁₆[j]} = {1, 2, ..., 16}

但 Sudoku 的列約束已要求：{R₀[j], R₁[j], ..., R₁₅[j]} = {1, 2, ..., 16}

因此 R₁₆[j] ∈ {1, 2, ..., 16} 必然與某個 Rᵢ[j] 衝突！

矛盾。故 R₁₆ 不存在。 ✓
```

### 3.3 推論

```
推論 1：符闔排列不能「混合使用」
  - 不能從不同 Sudoku 中各取幾行組成新網格
  - 必須從同一 Sudoku 的 16 行中選擇

推論 2：排列池的使用方式
  - 排列池是「概念庫」，不是「組合庫」
  - 實際使用時，應選擇整個 Sudoku（16 行）

推論 3：溢出不可避免
  - 只要排列不在同一 Sudoku 中，就必然有列衝突
  - 原始 1,111,494 個排列中，大部分必然溢出
```
