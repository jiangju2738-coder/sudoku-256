## 一、融闔三大架構總覽

### 架構一：92錨點神經網絡

| 指標 | 數值 |
|------|------|
| 錨點總數 | 92個 (佔網格 35.9%) |
| 符闔行固定行 | C, D, I (各16錨點，完全固定) |
| P行錨點 | 2個 (部分固定) |
| 符闔排列來源 | 64卦選取16個值，共1,111,494種排列 |
| 行約束 | A1-A16，每行16種有效排列選擇 |

**核心發現**:
- 符闔行 C/D/I 錨點密度 100%，形成不可變更的「量子態坍縮」
- A行與C行存在4個列衝突（3, 6, 8, 12），D行與H行有1個列衝突（8）
- 宮衝突：J6=L7=14（宮(2,1)）

### 架構二：搜索空間分析

| 維度 | 計算 | 量級 |
|------|------|------|
| 初始空間 | 16^(256-92) | ~10^198 |
| 符闔排列約束 | 每行16種排列 | ~10^177 |

**關鍵結論**:
- 符闔排列約束顯著減少搜索空間（相比標準數獨減少 ~10^20 倍）
- 列AllDifferent是最強約束，但與符闔排列形成「鎖定鏈」
- AC-3弧一致性在宮衝突檢測上效率極高（0.1秒發現 J6=L7=14）

### 架構三：約束衝突診斷

| 衝突類型 | 數量 | 根源 |

- Level 2: 符闔排列約束
- Level 3: 行約束
- Level 4: 列約束（非符闔優先，符闔鬆綁）
- Level 5: 宫約束（非符闔標準，符闔鬆綁）

## 二、連環遊戲博弈融闔映射

### 2.1 九連環（格雷碼） ↔ AC-3約束傳播

```
九連環原理:
┌────────────────────────────────────────────────────────┐
│  第n環能否取下/裝上 ← 取決於第n-1環狀態                  │
│  狀態空間: 2^n → 格雷碼序: 000 → 001 → 011 → 010       │
│  遞歸性質: f(n) = f(n-1) + 1 + f(n-1)                   │
└────────────────────────────────────────────────────────┘

AC-3傳播序（對應）:
┌────────────────────────────────────────────────────────┐
│  arc (xi, xj): xi的值域受xj約束                         │
│  Revise(xi, xj): 刪除與xj所有值不一致的xi值             │
│  傳播鏈: A3=3 → 列3其他格刪除3 → 宮(0,1)其他格刪除3     │
│  遞歸性質: arc队列傳播，直到無變化（固定點）              │
│  本例: 12行×16列×16宮 = 960個弧，傳播序類似格雷碼       │
└────────────────────────────────────────────────────────┘
```

**映射關係**:
- 九連環「第n環依賴第n-1環」 ↔ AC-3「arc(xi,xj)依賴arc(xj,xk)」
- 格雷碼遞歸步數 2^n-1 ↔ AC-3弧队列傳播次數（最壞情況）
- **本例發現**: AC-3在0.1秒內精確定位宮衝突，類似九連環「遞歸到底」

---

### 2.2 十六連環 ↔ 16×16行約束

```
十六連環原理:
┌────────────────────────────────────────────────────────┐
│  16個連環串聯，每個環有2^16=65536種狀態                │
│  總狀態空間: 2^16 → 需要特定順序解開                   │
└────────────────────────────────────────────────────────┘

符闔行約束（對應）:
┌────────────────────────────────────────────────────────┐
│  16行，每行16種符闔排列選擇                            │
│  行排列組合: 16^16 ≈ 10^20                             │
│  符闔排列約束: 每行從1,111,494種排列中選擇1種          │
│  全排列組合: (1.1M)^16 ≈ 10^9⁶                         │
└────────────────────────────────────────────────────────┘
```

**映射關係**:
- 十六連環狀態 2^16 ↔ 符闔行排列組合 (1.1M)^16
- 「必須按順序解開」 ↔ 「符闔行C/D/I固定後，其他行才能逐步求解」
- **本例發現**: 符闔排列約束將搜索空間壓縮至 10^177 → 10^156

---

### 2.3 華容道（排列奇偶） ↔ AllDifferent約束

```
華容道原理:
┌────────────────────────────────────────────────────────┐
│  排列奇偶性不變：每次移動是交換兩塊                     │
│  15-puzzle可解性: 排列奇偶性 + 空白位置奇偶性           │
│  數學: S_n 中的偶排列子群 A_n (指標2)                  │
└────────────────────────────────────────────────────────┘

AllDifferent約束（對應）:
┌────────────────────────────────────────────────────────┐
│  列約束: 每列16個格子填入1-16各一次 → S_16排列         │
│  宮約束: 每個4×4宫填入1-16各一次 → S_16排列           │
│  行約束: 每行16個格子填入1-16各一次 → S_16排列         │
│  符闔行: 從1,111,494種子群中選擇排列                   │
└────────────────────────────────────────────────────────┘
```

**映射關係**:
- 華容道「排列奇偶性」 ↔ 數獨「AllDifferent約束」
- A_n 子群指標2 ↔ 符闔排列子群指標 (16!/1.1M ≈ 1.5×10^8)
- **本例發現**: 符闔行C/D之間的宮衝突（如宮(0,0)中C1=7與D4=7）驗證了「約束奇偶性」
