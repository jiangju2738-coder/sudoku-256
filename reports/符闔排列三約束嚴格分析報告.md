## 二、溢出原因分析

### 2.1 理論根源

**關鍵數學事實**：
- 使用 CORRECT_SHIFTS 的 16 行 Sudoku，每列已經包含 {1,2,...,16} 各一次
- 這意味著：任意一個 16×16 Sudoku 的 16 行是**「極大列相容集」**
- 無法從外部找到第 17 行與它們共存於列約束下！

**證明**：
```
對於列 j，16 行的值 = {(j + CORRECT_SHIFTS[i]) mod 16 + 1 | i = 0,1,...,15}
                    = {(j+0) mod 16 + 1, (j+1) mod 16 + 1, ..., (j+15) mod 16 + 1}
                    = {1, 2, 3, ..., 16}
```

### 2.2 溢出類型

| 溢出類型 | 原因 | 影響 |
|---------|------|------|
| **循環移位溢出** | 非4倍數移位破壞列結構 | 每列值重複 |
| **值替換溢出** | 映射不保持宮間關係 | 宮約束違反 |
| **卦序映射溢出** | 排列生成未考慮列相容性 | 列值衝突 |

## 四、重要理論結論

### 4.1 修正原觀點

**原觀點**：
> "1,111,494 個符闔排列滿足行約束規則，其實也滿足列約束和宮約束"

**修正後的正確表述**：
> "符闔排列池中的排列，若**來自同一個 Sudoku**，則它們組成的 16×16 網格滿足行、列、宮三約束。但從池中**任意選取 16 個排列**，滿足三約束的概率極低（本實驗為 0%）。"

### 4.2 極大相容集理論

```
定理：任意 16×16 Sudoku 的 16 行構成「極大列相容集」

證明：
- 設 S = {R0, R1, ..., R15} 是一個 Sudoku 的 16 行
- 對於任意列 j，{Ri[j] | i=0..15} = {1,2,...,16}
- 若存在第 17 行 R16 與 S 列相容
- 則 {R16[j]} 必須不在 {R0[j], ..., R15[j]} 中
- 但 {R0[j], ..., R15[j]} 已占滿 {1,2,...,16}
- 矛盾！因此 R16 不存在

推論：符闔排列池中的排列不能「混合使用」，必須從同一 Sudoku 的 16 行中選擇
```

**您的發現是正確的！** 溢出現象確實存在，其根本原因是：

1. **列約束是極強约束**：16×16 Sudoku 的每一列已包含所有值
