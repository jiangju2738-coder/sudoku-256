## 符阖三约束的完整形式化定义

### 第一层：数独三约束（标准约束）

$$
\begin{aligned}
&\text{Row Constraint:} && \forall r \in \{1..16\}, \{cell(r, c) \mid c \in \{1..16\}\} = \{1,2,...,16\} \\
&\text{Column Constraint:} && \forall c \in \{1..16\}, \{cell(r, c) \mid r \in \{1..16\}\} = \{1,2,...,16\} \\
&\text{Box Constraint:} && \forall (i,j) \in \{0,1\}^2, \{cell(2i+1..2i+2, 2j+1..2j+2)\} = \{1,2,3,4\}
\end{aligned}
$$

### 第二层：符阖排列约束（部分实现）

$$
\forall r \in \{A..P\}, \text{Row}_r \in A^r_{\text{permutations}}
$$

其中 $A^r_{\text{permutations}}$ 是第 $r$ 行的符阖排列集合。

**当前状态：**
- 原始集合规模：~1,360,849 个排列
- 重新生成集合规模：~38,182 个排列
- 规模缩小约 35.6 倍

### 第三层：符阖排列组闔（缺少实现！）

$$
\forall r \in \{A..P\}, \text{Row}_r = A^r_{k_r}
$$

其中 $A^r_{k_r}$ 是第 $r$ 行符阖排列组闔中的**第 $k_r$ 个预定义排列**。

**关键区别：**
- 第二层：行可以**从集合中选择**任意一个排列
- 第三层：行**必须是**特定的预定义排列

## 核心证明链总结

### 证明目标
$$
\text{92 Anchors + Sudoku 3 Constraints} \neq \text{Original Fummel Problem}
$$

### 证据链

| 证据 | 发现 | 结论 |
|------|------|------|
| **行C对比** | CP-SAT解 vs TXT终局C191620 仅匹配 5/16 | 两个不同解 |
| **92锚点验证** | CP-SAT解 92/92 锚点全部满足 | CP-SAT执行正确 |
| **符阖排列组闔** | CP-SAT解 0/16 行在原始集合中 | **缺少关键约束** |
| **C191620位置** | 不在重新生成的A3集合中 | 原始集合规模 > 再生集合 |

### 逻辑推导

```
前提1: CP-SAT使用92锚点+数独三约束求解
       → 返回"唯一解"（0.14秒）

前提2: TXT终局解盘行C = C191620
       → 满足所有92锚点约束
       → 满足所有列约束
       → 但不在我们的重新生成符阖排列集合中

关键事实:
  CP-SAT解行C ≠ TXT终局C191620 (仅5/16匹配)

推论:
  如果 "92锚点+数独三约束" = "符阖原题"
  那么 CP-SAT的"唯一解"应该等于TXT终局解盘
  但CP-SAT解与TXT终局解盘不同
  → 矛盾！

结论:
  92锚点+数独三约束 ≠ 符阖原题
  
  符阖原题还包含第三层约束：
  符阖排列组闔 - 每行必须是预定义的完整排列
```

## 最终结论

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  符阖三约束 = 数独三约束 + 符阖排列约束 + 符阖排列组闔                         │
│                                                                             │
│  数独三约束（标准）：行/列/宫互斥                                               │
│  符阖排列约束（部分实现）：每行来自对应的A{i}集合                                 │
│  符阖排列组闔（缺少实现）：每行是预定义的完整排列                                   │
│                                                                             │
│  ─────────────────────────────────────────────────────────────────────────  │
│                                                                             │
│  92锚点 + 数独三约束 ≠ 符阖原题                                               │
│                                                                             │
│  原因：                                                                      │
│  - 92锚点只固定256宫格中的92个位置                                           │
│  - 剩余151个位置仍有无数种可能填充方式                                        │
│  - 符阖排列组闔将解空间压缩到有限种可能                                        │
│  - TXT文件中的"终局解盘"是预定义答案，不是推导结果                              │
│                                                                             │
│  ─────────────────────────────────────────────────────────────────────────  │
│                                                                             │
│  符阖排列组闔的本质：                                                        │
│  - 不是从数独约束推导出来的排列集合                                          │
│  - 而是与易經六十四卦象数逻辑相关的预定义结构                                  │
│  - 需要跨领域研究才能完整理解和实现                                            │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
