三、标准数独 vs 自由变体基因指纹判据体系

判据1：综闔博弈均衡度 (D91)

  • D91 > 0.5 : 标准数独特征 - 行间约束均衡，无主导行
  • D91 ≤ 0.5 : 自由变体特征 - 存在主导行，约束不均匀

判据2：五维线锁定度 (D93)

  • D93 = 0 : 标准数独 - 仅行列宫三重约束
  • D93 > 0 : 自由变体 - 存在额外约束维度（如X数独对角线、Killer数独Cage等）

判据3：基因综合评分 (D100)

  • D100 < 65 : 强约束谜题（演进谜题，存在主导行）
  • D100 ≥ 65 : 标准谜题（初始盘，约束相对均衡）
  • D100 = 100 : 完全解盘（16行全部锁定）

五、核心结论

1. 符闔数独的本质分类

符闔排列数独系统本质上是自由变体数独，原因如下：

  • 行级约束增强：每行需从特定的符闔排列集合中选择（A行8,731个、I行164个、C行656,777个等）
  • 排列集合约束：相当于在标准数独行约束基础上，增加了"行必须属于某排列集合"的额外约束
  • 非标准分布：各自行排列数量差异极大（164 vs 656,777），导致约束强度极度不均匀

2. 演进谜题的自由变体特征

  • 单行完全锁定（100%）+ 其他行部分锁定（18.75%-50%）→ 典型的"主导者-参与者"博弈结构
  • 额外排列约束维度（D93 > 0）→ 超出标准数独的行列宫三重约束
  • 基因评分58-62分 → 属于强约束自由变体谜题

3. 初始盘的特殊性

初始盘92锚点是"边界案例"：

  • D93 = 0 → 无显式的额外维度约束（看似标准数独）
  • D91 = 0.36 → 存在行约束不均匀（自由变体特征）
  • 结论：初始盘是标准数独与自由变体的过渡态，具有自由变体的不均匀性但未引入显式额外约束

4. 与其他自由变体的对比

变体类型额外约束类似符闔数独
X数独两条对角线否（作用于对角线而非行）

字母数独字母排列部分（也是排列约束）
符闔数独行级排列集合自创类型

5. 最终判定

根据基因指纹100D维度分析：

  • 符闔数独不是标准数独 - 存在行级排列集合约束（自由变体特征）
  • 符闔数独是独特的自由变体 - 约束作用于行级排列集合，而非传统对角线/区域/求和
  • 演进谜题是典型的行锁定型自由变体 - 单行100%锁定 + 排列约束
  • 初始盘是过渡态 - 具有不均匀性但无显式额外约束
