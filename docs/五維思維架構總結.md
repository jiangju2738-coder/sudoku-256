## 📐 六維層次約束表達式

### 點層 (Point - 0D)

| 約束類型 | 表達式 | 复杂度 | 卦象 |
|---------|--------|--------|------|
| 值域約束 | `Cell(r,c) ∈ {1..16}` | O(1) | 坤䷁ |
| 唯一性 | `Unique(Cell(r,c))` | O(1) | 復䷗ |
| 初值 | `Given(Cell(r,c)) = v₀` | O(1) | 乾䷀ |

```python
# Python 實現
cell = Cell(row=r, col=c, box=box_idx)
cell.domain = {1,2,3,...,16}
cell.set_value(v)  # 縮小域為單點
```

---

### 線層 (Line - 1D)

| 約束類型 | 表達式 | 复杂度 | 卦象 |
|---------|--------|--------|------|
| 行全不同 | `AllDifferent(Row(r))` | O(n log n) | 乾䷀ |
| 列全不同 | `AllDifferent(Col(c))` | O(n log n) | 坤䷁ |
| 行和 | `Sum(Row(r)) = 136` | O(n) | 泰䷊ |

```python
# Python 實現
row = Line(line_type='row', index=r)
for c in range(16):
    row.add_cell(point.get_cell(r, c))
row.propagate()  # 約束傳播
```

---

### 面層 (Plane - 2D)

| 約束類型 | 表達式 | 复杂度 | 卦象 |
|---------|--------|--------|------|
| 宮格全不同 | `AllDifferent(Plane(g))` | O(n²) | 咸䷞ |
| 宮格和 | `Sum(Plane(g)) = 136` | O(n²) | 恆䷟ |
| 宮格對稱 | `Plane(g) = Symmetry(Plane(g))` | O(n²) | 既濟䷾ |

```python
# Python 實現
plane = Plane(box_index=g, box_row=br, box_col=bc)
for r in range(br*4, (br+1)*4):
    for c in range(bc*4, (bc+1)*4):
        plane.add_cell(point.get_cell(r, c))
```

---

### 體層 (Body - 3D)

| 約束類型 | 表達式 | 复杂度 | 卦象 |
|---------|--------|--------|------|
| 網絡交集 | `B(r,c,g): Cell ∈ Row ∩ Col ∩ Plane` | O(n³) | 復䷗ |
| 對角線 | `AllDifferent({Cell(i,i)})` | O(n) | 損䷨ |
| 全一致 | `Consistent(Rows ∪ Cols ∪ Planes)` | O(n³) | 乾䷀ |

```python
# Python 實現
body = BodyConstraint(point, line, plane)
body.propagate()  # 三維約束網絡傳播
body.check_all_consistency()  # 全一致性檢查
```

---

### 球層 (Sphere - 4D)

| 約束類型 | 表達式 | 复杂度 | 卦象 |
|---------|--------|--------|------|
| 漢明距離 | `H(s₁,s₂) = Σᵢ [s₁[i] ≠ s₂[i]]` | O(n²) | 大過䷛ |
| 球面投影 | `π: S → Sⁿ (n維單位球面)` | O(n²) | 萃䷬ |
| 解空間密度 | `ρ = |S| / Volume(Sphere)` | O(n³) | 小過䷽ |

```python
# Python 實現
state1 = SphereState(solution_vector=vec1)
state2 = SphereState(solution_vector=vec2)
dist = state1.hamming_distance(state2)
normalized = state1.normalize_to_sphere()
```

### 時空層 (Space-Time - 5D)

| 約束類型 | 表達式 | 复杂度 | 卦象 |
|---------|--------|--------|------|
| 搜索狀態 | `State(t) = {Cells(t), Constraints(t), Path(t)}` | O(b^d) | 未濟䷿ |
| 約束傳播 | `AC-3 / MAC / Forward Checking` | O(n³) | 既濟䷾ |
| 回溯優化 | `Backtrack + Pruning` | O(b^d) | 泰䷊ |

```python
# Python 實現
search_state = SearchState(
    time_step=t,
    point=system.point,
    constraints_pass=pass_count,
    backtracks=backtrack_count
)
```

## 🔧 層間轉化規則

### 轉化通道

```
點 → 線:
  P(r,c,v) → L_row(r, AllDiff) ∧ L_col(c, AllDiff)
  (單點確定 → 約束該點所屬行列)

線 → 面:
  L_row(r) ∧ L_col(c) → P_plane(g, AllDiff)
  (行列交集 → 約束所屬宮格)

面 → 體:
  P_plane(0..15) → B(Network)
  (16宮格 → 全局約束網絡)

體 → 球:
  B(Network) → Φ(Sphere)
  (約束網絡 → 解空間球體)

球 → 時空:
  Φ(Sphere) → State(t)
  (解空間 → 搜索演化過程)

時空 → 點:
  State(t) → P(r,c,v')
  (搜索狀態 → 新的單元格確定)
```

## 🎯 使用範例

```python
from 五維思維系統 import FiveDimensionalFramework, FrameworkConfig

# 1. 創建框架
config = FrameworkConfig(
    grid_size=16,
    box_size=4,
    use_hexagram=True,      # 啟用卦象優化
    use_symmetry=True,      # 啟用對稱性破缺
    max_backtracks=100,
    prune_threshold=0.5,
    search_strategy="backtrack",
    verbose=True
)

framework = FiveDimensionalFramework(config)

# 2. 載入題目
puzzle = {
    (0, 0): 1, (0, 1): 2, (0, 2): 3, (0, 3): 4,
    (0, 12): 13, (0, 13): 14, (0, 14): 15, (0, 15): 16,
    # ... 更多初值
}
framework.load_puzzle(puzzle)

# 3. 顯示五維架構
framework.display_constraint_hierarchy()

# 4. 取得卦象分析
analysis = framework.get_hexagram_analysis()
print(f"當前卦象: {analysis['hexagram']}{analysis['symbol']}")
print(f"建議: {analysis['recommendation']}")

# 5. 求解
framework.solve()

# 6. 顯示結果
framework.display_solution()
framework.display_hexagram_evolution()
```
